# Power Eagle

Breaking rebuild using a new declarative document language and composable contribution packages.

```sh
npm ci
npm run dev
```

Current app: a Sources / Stage / Agent workbench with validated runtime documents,
compiled contribution packages, package acquisition controls and a built-in widget
catalog. Release and live-host acceptance are still incomplete; see the
[remaining-work ledger](docs/remaining-work.md).
