# Power Eagle

Breaking rebuild using a new declarative document language and composable contribution packages.

```sh
npm ci
npm run dev
```

Current app: an interactive validated runtime example with typed state, bindings, keyed repetition, composed actions, and screen navigation. The full workbench and release widget catalog are still being implemented.
